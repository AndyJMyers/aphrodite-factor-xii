# Aphrodite Factor XII

## *How Gods, Goddesses and Sorceresses Get Their Own Way*
### *...and How You Can Too*

Commercial narrative non-fiction / humorous psychology proposal by Andy J Myers.

This repository holds the working manuscript, agent proposal material, structural notes, and approved visual assets for the project.

- `proposal/AGENT-PITCH.md` — one-page agent pitch
- `proposal/SYNOPSIS.md` — book synopsis and chapter structure
- `manuscript/chapter-01-golden-apple.md` — first sample chapter

## Working premise

Nothing much has changed psychologically in three thousand years. People still want status, admiration, love, allies, favourable gossip, free wine, and someone dependable when the amphorae need moving. The Greek gods knew exactly how to obtain these things, often with disastrous results. Their tactics are examined by Dionysus and Penelope: one the god of appetite and ecstatic persuasion, the other the patron saint of patience, standards and the long game.
